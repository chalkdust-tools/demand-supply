# 需要と供給のグラフ

公共・政治経済の授業で使う、需要曲線・供給曲線のアニメーション教材です。
ブラウザで `index.html` を開くだけで動きます（インストール不要）。

## できること

授業の流れにそって、問題に答えるとグラフが動きます。

1. 需要曲線（値段が下がると買いたい量は？）
2. 供給曲線（高く売れると売りたい量は？）
3. 均衡価格（売れ残り・品不足と「見えざる手」）
4. 需要が動く（曲線の上の移動と、曲線そのものの移動の違い）
5. 供給が動く
6. チャレンジ（どっちの曲線が動く？の見分け練習）
7. 自由実験（スライダーで自由に動かす）

## 先生向けの操作

- キーボード：`1`〜`4` で選択肢、`→` で次へ、`R` で動きをもう一度、`Esc` でトップへ
- プレゼン用リモコンの「次へ」ボタンでも進められます
- 右上の「文字を小さく」で、個人端末向けの大きさに切りかえられます

## メモ

- グラフの数値は説明用のモデルで、実際のデータではありません。
- 問題は `lesson.js` に入っています。ファイルの先頭に書き方の説明があります。
