# 需要と供給のグラフ

公共・政治経済の授業で使う、需要曲線・供給曲線のアニメーション教材です。
ブラウザで `index.html` を開くだけで動きます（インストール不要）。

## できること

授業の流れにそって、問題に答えるとグラフが動きます。1回目に間違えるとヒントが出て、もう一度選べます。

1. 需要曲線（値段が下がると買いたい量は？）
2. 供給曲線（高く売れると売りたい量は？）
3. 均衡価格（売れ残り・品不足と「見えざる手」）
4. 需要が動く（曲線の上の移動と、曲線そのものの移動の違い）
5. 供給が動く
6. チャレンジ（どっちの曲線が動く？の見分け練習）
7. 余剰（政治・経済向けの発展）
8. 価格統制（上限価格・下限価格と死荷重。政治・経済向けの発展）
＋ 自由実験（スライダーで自由に動かす）

## ワークシート

`worksheet.html` を開くと、問題と同じ内容のA4プリントが作られます。印刷する章を選べて、「解答を入れる」で先生用の解答版になります。問題を `lesson.js` に足すと、プリントにも自動で入ります。

## 自習プリント

`jishu.html` を開くと、選んだ章から問題をランダムに選んで、自習用のプリントを作ります。

- 問題の数（5・10・15・20問くらい／全部）、並び順、解答・解説の付け方（別ページ・すぐ下・なし）を選べます
- 「このとき〜」でつながる問題は、セットのまま出ます
- 右上の「No.」が同じなら同じ問題になるので、`jishu.html?no=1234` のように開くと同じプリントを作り直せます

## 先生向けの操作

- キーボード：`1`〜`4` で選択肢、`→` で次へ、`R` で動きをもう一度、`Esc` でトップへ
- プレゼン用リモコンの「次へ」ボタンでも進められます
- 右上の「文字を小さく」で、個人端末向けの大きさに切りかえられます

## メモ

- グラフの数値は説明用のモデルで、実際のデータではありません。
- 問題は `lesson.js` に入っています。ファイルの先頭に書き方の説明があります。
